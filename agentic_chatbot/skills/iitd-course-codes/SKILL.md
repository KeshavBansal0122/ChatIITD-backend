## Course Code Format

Legacy courses for entry year 2024 and earlier usually use `XXX###`, e.g. `COL380`.
The 2025+ curriculum often uses four digits, e.g. `COL1000`, `COL1101`.

For course prefixes:
- Letters 1-2 identify the academic unit, e.g. `CO` for Computer Science and Engineering, `EL` for Electrical Engineering.
- Letter 3 identifies the course type: `L` lecture, `P` practical, `D` project, `N` non-graded, `V` special module, `S` independent study.
- Remaining digits identify level / number.
